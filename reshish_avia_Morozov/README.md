# Решись Авиа — Сервис прогнозирования спроса и продаж (Вариант C)

**Автор:** Морозов Арсений Игоревич  
**Данные прогноза:** `Morozov_Arseniy_Igorevich_my_forecast.csv`

## Реализованный функционал
* **Backend API (Python / Flask):** обработка данных прогноза, расчёт спроса по линейной эластичности и ограничение продаж вместимостью борта (`seats`).
* **Frontend (HTML / CSS / JavaScript):** форма выбора маршрута из Москвы, даты вылета и цены билета с мгновенным выводом результатов через `fetch`.
* **График распределения спроса (Chart.js):** визуализация спроса и ожидаемых продаж по всем 9 квантилям (`0.1` — `0.9`) с отметкой вместимости самолёта.
* **Регистрация и авторизация:** система учётных записей на базе SQLite и серверных сессий Flask.

## Использование технологий ИИ
При разработке проекта использовалась большая языковая модель **Gemini** для проектирования архитектуры веб-приложения, генерации кода backend-сервера (Python/Flask), верстки пользовательского интерфейса и настройки графиков (Chart.js).

## Запуск проекта локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите сервер: `python app.py`
3. Откройте в браузере: `http://127.0.0.1:5000`
